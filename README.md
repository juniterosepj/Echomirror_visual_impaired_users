# EchoMirror Pro
Assistive smart mirror built on ESP32 Wroom 32E

**MCU:** ESP32 Wroom 32E  
**Sensors:** APDS9960 (I2C), BMP180 (I2C), DHT11, MQ135 (ADC), Sound sensor  
**Output:** 128x64 OLED + PAM8403 amplified speaker + Buzzer
